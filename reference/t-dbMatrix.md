# Matrix Transpose

Given a
[`dbMatrix`](https://dbverse-org.github.io/dbmatrix-r/reference/dbMatrix.md)
`x`, `t` returns the transpose of `x`.

## Usage

``` r
# S4 method for class 'dbMatrix'
t(x)
```

## Arguments

- x:

  [`dbMatrix`](https://dbverse-org.github.io/dbmatrix-r/reference/dbMatrix.md)
  object

## Value

[`dbMatrix`](https://dbverse-org.github.io/dbmatrix-r/reference/dbMatrix.md)
object
